# CLI Design

The CLI program is named **`shenctl`** and will display help information when invoked without arguments.

## Authentication

```bash
shenctl auth login               # Login with username and password
shenctl auth logout              # Logout and revoke current session
```

## Configuration Management

Configuration is stored in `$XDG_CONFIG_HOME/shenctl/config.toml` (default: `~/.config/shenctl/config.toml`).

```bash
shenctl config list              # List all configuration values
shenctl config get <key>         # Get a specific configuration value
shenctl config set <key> <value> # Set a configuration value
shenctl config unset <key>       # Remove a configuration value
```

## User Management

```bash
shenctl user list                                           # List all users
shenctl user list --limit <n> --cursor <cursor>             # List with pagination (cursor-based)
shenctl user create <user-name> <role>                      # Create a new user
                                                            # Role: service, user, or admin
shenctl user update <user-name> [--role <role>] [--password]  # Update user (role: admin only, password: self or admin)
shenctl user delete <user-name>                             # Soft delete (mark as inactive)
shenctl user add-groups <user-name> <group1> <group2> ...   # Add user to groups
```

## Group Management

```bash
shenctl group list                                          # List all groups
shenctl group list --limit <n> --cursor <cursor>            # List with pagination (cursor-based)
shenctl group create <group-name>                           # Create a new group (admin only)
shenctl group delete <group-name>                           # Delete a group (admin only)
shenctl group add-users <group-name> <user1> <user2> ...    # Add users to group (admin or group manager)
shenctl group remove-users <group-name> <user1> <user2> ... # Remove users from group (admin or group manager)
shenctl group add-role <group-name> <application> <role>    # Add a role to group for application (admin only)
shenctl group remove-role <group-name> <application> <role> # Remove a role from group for application (admin only)
shenctl group list-roles <group-name> [application]         # List roles for group (optionally filtered by application)
shenctl group add-managers <group-name> <user1> <user2> ... # Assign group managers (admin only)
shenctl group remove-managers <group-name> <user1> ...      # Remove group managers (admin only)
shenctl group list-managers <group-name>                    # List managers of a group
```

## Application Management

```bash
shenctl application list                          # List all applications
shenctl application list --limit <n> --cursor <cursor>  # List with pagination (cursor-based)
shenctl application create <application-name>     # Create a new application
shenctl application delete <application-name>     # Soft delete (mark as inactive)
```

## Token Management

```bash
# List tokens
shenctl token list                           # List your own tokens
shenctl token list --limit <n> --cursor <cursor>       # List with pagination (cursor-based)
shenctl token list --user <username>         # List tokens for specific user (admin only)
shenctl token list --user <username> --limit <n> --cursor <cursor>  # List user tokens with pagination

# Create tokens
shenctl token create <token-name> <application>         # Create token for yourself
shenctl token create <token-name> <application> <user>  # Create token for specific user (admin only)

# Revoke tokens
shenctl token revoke <id>                    # Revoke a specific token by ID
shenctl token revoke-all <username>          # Revoke all tokens for a user (admin only)

# Cleanup
shenctl token cleanup                        # Remove expired and revoked tokens (admin only)
```

## Session Management

```bash
# List sessions
shenctl session list                         # List your own sessions
shenctl session list --limit <n> --cursor <cursor>      # List with pagination (cursor-based)
shenctl session list --user <username>       # List sessions for specific user (admin only)
shenctl session list --user <username> --limit <n> --cursor <cursor>  # List user sessions with pagination

# Revoke sessions
shenctl session revoke <id>                  # Revoke a specific session by ID
shenctl session revoke-all <username>        # Revoke all sessions for a user (admin only)
```
